## 1. Что сделано

### Основные страницы сайта
- **Главная** — hero-секция, категории, хиты продаж, блок доверия, футер
- **Каталог** — список товаров с фильтрацией по категориям и поиском
- **Карточка товара** — галерея, выбор размера и цвета, кнопка в корзину

- **Оформление заказа** — форма с контактами, адресом, выбором доставки и оплаты
- **Доставка и оплата** — информация о способах доставки и оплаты
- **Возврат** — условия и инструкция по возврату

### Функциональность
- Загрузка товаров из базы данных Supabase
- Корзина с расчётом суммы
- Отправка заказа владельцу в Telegram
- Веб-админка для управления товарами
- Загрузка фотографий товаров в облачное хранилище
- Фильтрация товаров по категориям

## 3. Схема связей — что от чего зависит

```
Клиент открывает сайт
        ↓
GitHub Pages отдаёт index.html
        ↓
Сайт запрашивает товары → Supabase (таблица products)
        ↓
Фотографии товаров → Supabase Storage (бакет products)
        ↓
Клиент оформляет заказ → Telegram Bot API → Сообщение владельцу

Владелец управляет товарами:
admin.html → Supabase (добавить/изменить/удалить товар)
           → Supabase Storage (загрузить фото)
```

**Зависимости:**
- Если упадёт GitHub — сайт недоступен (бесплатный хостинг, редко)
- Если упадёт Supabase — товары не загрузятся (надёжный сервис)
- Если упадёт Telegram API — заказы не придут в Telegram, но сайт работает

## 5. Что нужно для поддержания сайта в интернете

### Регулярные действия

**Ничего особенного делать не нужно.** Сайт работает автоматически 24/7. Но есть несколько вещей на будущее:

**Раз в год:**
- Продлить домен (если будет куплен свой домен — сейчас сайт работает на бесплатном адресе GitHub)

**Раз в 1-2 года:**
- Проверить лимиты Supabase (бесплатный план: 500 МБ БД, 1 ГБ хранилище). Если исчерпается — перейти на платный план (~$25/мес) или очистить старые фото

**По необходимости:**
- Обновлять товары через админку
- Менять тексты и контакты на сайте через GitHub (редактировать `index.html`)

### Что может сломаться и как чинить

| Проблема | Причина | Решение |
|----------|---------|---------|
| Сайт не открывается | GitHub Pages временно недоступен | Подождать 10-30 минут |
| Товары не загружаются | Проблема с Supabase | Проверить статус на status.supabase.com |
| Заказы не приходят в Telegram | Бот заблокирован или сломан | Написать /start боту в Telegram |
| Фото не загружаются в админке | Исчерпан лимит хранилища | Удалить старые фото или перейти на платный план |

## 6. Что ещё не сделано (для полноценного магазина)

### Критично для запуска продаж
- **Приём оплаты (ЮKassa)** — сейчас форма оплаты есть, но деньги не списываются. Нужно подключить ЮKassa (~2-3% комиссия с каждого заказа). Требует ИП или самозанятость.
- **Реальные контакты** — в футере сейчас заглушки (`info@void.ru`, `+7 (800) 555-00-00`)
- **Реальные фотографии** — сейчас тестовые фото

### Желательно
- **Свой домен** — например `void.ru` или `void-shop.ru` (стоимость ~500-1500₽/год)
- **Страница «О нас»** — история бренда, команда
- **Telegram-бот для добавления товаров** — чтобы добавлять товары с телефона без компьютера
- **Учёт остатков** — сейчас нет контроля сколько единиц в наличии
- **Личный кабинет покупателя** — история заказов
- **Сохранение заказов в базу** — сейчас заказы только в Telegram, не сохраняются
